# ReportCatcher

MoonLoader-скрипт для **SA-MP**, сделан под серверы **Arizona RP**. Автоматически спамит команду `/ot`, пока сервер не пришлёт ответ о принятии репорта — то есть помогает раньше других поймать репорт. Имеет графический интерфейс (mimgui), лог пойманных репортов и проверку обновлений.

## Возможности

- **Хоткей вкл/выкл** — по умолчанию `R`, можно переназначить в меню.
- **Автоспам команды** `/ot` с настраиваемым количеством повторов, задержкой между ними и интервалом между сериями.
- **Индикатор на экране** — показывает статус, время с начала попытки и количество отправленных команд, с анимацией и плавным исчезновением при успехе.
- **Меню настроек** (`/rcmenu`) — смена хоткея, перетаскивание окон индикатора и логгера.
- **Окно логгера репортов** (`/rclog`) — история пойманных репортов (ник, ID, текст, дата/время) с поиском по тексту, хранится в `config/RCLog.txt`.
- **Проверка обновлений** — при запуске скрипт сверяет свою версию с версией на GitHub; если найдена новая, скрипт блокирует работу и просит запустить `/rcupdate`, после чего сам скачивает и заменяет свой файл.
- **Сохранение настроек** — позиции окон и хоткей сохраняются в `config/RCSettings.ini`.

## Команды

| Команда     | Действие                                  |
|-------------|--------------------------------------------|
| `/rcmenu`   | Открыть/закрыть меню настроек              |
| `/rclog`    | Открыть/закрыть окно логгера репортов      |
| `/rcupdate` | Скачать и установить найденное обновление  |

Хоткей для запуска/остановки автоспама задаётся в меню (по умолчанию `R`).

## Требования

- [MoonLoader](https://blast.hk/moonloader/) для SA-MP.
- Библиотеки: `lib.samp.events`, `mimgui`, `vkeys`, `fAwesome5`, `encoding`.
- Установленный клиент SA-MP.

## Установка

1. Скачайте `ReportCatcher.luac`
2. Поместите файл в папку `moonloader/` вашего SA-MP клиента.
3. Запустите игру — скрипт загрузится автоматически и напишет в чат сообщение о готовности.

## Файлы данных

Скрипт создаёт папку `moonloader/config/` и хранит в ней:
- `RCSettings.ini` — позиции окон и хоткей;
- `RCLog.txt` — история пойманных репортов.

## Дисклеймер

Скрипт автоматизирует действия в игре (массовую отправку команды). На некоторых RP-серверах использование автоматизации/макросов может быть запрещено правилами — перед использованием ознакомьтесь с правилами вашего сервера. Автор не несёт ответственности за возможные санкции со стороны администрации серверов.
